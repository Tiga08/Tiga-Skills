# post.md：分平台文案模板

每个发布包一份。`check.py` 按下面的格式校验：两个二级标题、`标题：`/`正文：`/`话题：` 字段名不能改。

```markdown
# <视频标题>

## 小红书

标题：<不超过 20 字，用户在方案里选定的那条>

正文：
<3–6 短行，口语化，像店主在和熟客聊天；可带 emoji；最后一行引导到店或互动>

话题：#咖啡店 #拿铁 #… （5–8 个）

## 抖音 / 视频号

标题：<一句话，说清画面里发生了什么或有什么新东西>

话题：#咖啡 #… （3–5 个）
```

- 封面字用小红书标题。cover.py 会自动去掉 emoji，字体里没有这些字形。
- 话题标签：前两三个用大流量词（#咖啡、#探店），后面用具体词（饮品名、城市、季节）。
- `brand.md` 的语气、称呼一旦填好，就以它为准；还是“待提供”的项，按上面的默认口吻写。
